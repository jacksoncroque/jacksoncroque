## 💡 Sobre mim

Sou um desenvolvedor Front-end, cursando Análise e Desenvolvimento de Sistemas e construindo aplicações web com foco em interfaces modernas, responsivas e bem estruturadas.

Tenho interesse em criar experiências visuais consistentes e funcionais, aplicando boas práticas de desenvolvimento e organização de código.

Também possuo alguns conhecimentos em back-end, com experiência em Python e SQL para manipulação de dados e lógica de aplicações.
